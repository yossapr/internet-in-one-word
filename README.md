An entry for make.fun's *The Internet in One Word* bounty: the whole internet, in one word.

## Run it

```sh
node main.ts
```

The program writes `/output/entry.txt` with the word from `entry.txt` (set `MAKEFUN_OUTPUT_DIR`
to write somewhere else). Standard library only, no network.
